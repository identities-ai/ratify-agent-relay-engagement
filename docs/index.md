# Example: verify before serve

A minimal reference showing a service that verifies a delegated-authority proof before it
does any work. It is intentionally small: one accept path, one refusal path, no framework.

This repository is a purpose-built stage for the Agent Relay x Ratify Phase 2 engagement.
It is not production software and holds nothing sensitive. The engagement's commits will
land here under bounded, revocable, offline-verifiable authority scoped to `/docs`.
